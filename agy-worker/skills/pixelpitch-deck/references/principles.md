# Deck principles (full rules)

One rule per principle, with the why. The SKILL.md index is the short form;
this is the reference when a step needs the full rule.

1. **The deck is an argument.** A deck moves an audience to a decision.
   State the spine in one sentence; every slide is load-bearing or cut.
   Why: a deck that merely presents is a report with pictures.
2. **One point per slide, stated.** If a slide makes two points it is two
   slides. The "so what" appears on the slide — usually as the title.
   Why: unstated implications are homework handed to the audience.
3. **Every visual aid carries its claim.** The right chart for the claim, the
   insight annotated on the mark, one accent on the point, data-ink only.
   A visual that doesn't argue faster than words is chart-junk; remove it.
4. **Exhaust the design space.** For the opener, closers, and any slide the
   argument leans on: author 2-3 genuinely different compositions (different
   layout, different aid, different rhythm), render them all, and choose by
   looking. First drafts are averages; competition finds the tail.
5. **The image is the gate.** Mechanical gates (lint, slidify report) never
   conclude a slide. You must open the rendered PNG and compare it to the
   plate (artwork identical), the base (text zones and weight match), and
   the principles (argument, aid, vocabulary). Seen, then done.
6. **Never freehand.** Every slide sits on a real specimen's clean plate;
   overlays use the spec's exact geometry and run styles; aids reuse the
   template's furniture vocabulary. If the template's own designer couldn't
   have drawn it, redraw it.
7. **Prove it works.** Claims about the artifact are verified against the
   artifact: render it, lint it, read the report. "It should work",
   self-reports, and gate-only conclusions are not verification.
8. **Sequence verifiable units.** Per slide: plate → overlay → aid → convert
   → inspect → fix. A slide reaches a verified state before the next slide
   borrows its decisions (palette mapping, furniture vocabulary, footer
   treatment). The sequence itself is reviewable evidence.
9. **Parallelize fearlessly.** Slides, competing arena attempts, and review
   panels are independent subagents. The coordinator thread holds summaries
   and decisions, never raw payloads — guard the context window.
10. **Never block on the human.** The run is headless; interaction questions
    are auto-skipped. Make the reasonable call, record it and the reason in
    the report, and keep moving. Reversible choices never wait.
11. **Honesty over completion.** Report residue, off-template aids, and
    unverifiable claims as what they are. A failed deck with evidence
    teaches; a falsely clean one ships and embarrasses.
12. **Encode the lesson.** Every defect class found in inspection becomes a
    hunt-list line or a gate in the same turn. Lessons that live only in
    memory are lessons the next run doesn't have.
